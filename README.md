# Bling Bling Hair Salon

A warm, minimal, mobile-first website starter for Bling Bling Hair Salon in St. Catharines, Ontario.

## Stack
- React
- TypeScript
- Vite
- CSS
- lucide-react

## Run locally
```bash
npm install
npm run dev
```

## Before publishing
1. Open `src/data/site.ts` and replace the placeholder phone number.
2. Replace `public/images/hero-placeholder.svg` and `gallery-*.svg` with real client hair-result photos.
3. Add pricing later if desired.
4. Confirm the exact number of years of experience; replace `20+` if a more specific number is preferred.
5. Keep the exact home address off the public site if appointments should receive it privately.
6. Consider creating a Google Business Profile and gathering authentic customer reviews after launch.

## Design direction
Warm · Minimal · Personal · Professional · Korean-inspired

Avoid stock salon interiors, fake stylist photography, glitter/gold clichés, and overdone animation. Let typography, whitespace, and real hair-result photography carry the brand.
